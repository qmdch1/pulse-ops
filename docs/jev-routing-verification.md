# Jev 자동 작업 배정 검증

검증일: 2026-10-09. Pulse Ops에 프로젝트·프롬프트를 등록하고 Jev 판단에 따라 Codex 또는 Claude CLI의 새 세션을 실행하는 기능입니다. 등록 프롬프트 하나가 작업 하나가 되며 여러 등록 작업을 설정한 수만큼 병렬로 처리합니다.

## 확인한 범위

- Docker Desktop의 `golang:1.27`에서 기본 빌드와 `-tags testseed` 각각 `go vet ./...`, `go test -race ./...` 통과. 모듈·빌드 캐시는 기존 명명 볼륨을 사용했습니다.
- Jev 요청·응답은 로컬 HTTP 서버로 검증했습니다. Bearer 인증, 실제 System One 질문 형식, 프롬프트·프로젝트 설명·담당 프로필 전달, 같은 프로젝트의 평가만 포함하는 동작, 낮은 확신도 보류, 잘못된 선택 확률·응답·HTTP 오류 거부를 확인했습니다. 분석 상태에 API 키나 로컬 프로젝트 경로를 포함하지 않습니다.
- 임시 실제 Git 저장소에서 독립 worktree와 브랜치를 생성했습니다. 원래 체크아웃의 커밋되지 않은 파일이 실행 공간에 들어가지 않고, 프롬프트가 명령문으로 해석되지 않고 표준 입력으로 전달되는 것을 확인했습니다.
- Codex·Claude의 JSON 프로토콜을 보내는 테스트 실행 파일로 새 세션 ID, 완료 응답, 사용량, 권한 거부, 실패·미완료 처리와 암호화된 결과 저장을 검증했습니다. 사용량 미제공과 실제 0을 구분합니다. 이 실행 파일은 실제 모델을 호출하지 않습니다.
- 동시 실행 제한, 작업 취소 시 프로세스 그룹 종료, 종료 대기와 중단 상태 저장, 재시작 후 기존 작업 공간 보존, 버전 충돌 거부, 명시적 재시도의 이전 실행 정보 초기화를 확인했습니다.
- 허용 프로젝트 경계와 심볼릭 링크·저장소 하위 폴더 거부, 기존 인증 적용, 키를 노출하지 않는 설정 편집·삭제, 완료 작업 평가와 목록의 실행 출력 제외를 검증했습니다.
- `python3 tests/ssh-discovery.test.py`: 2개 통과.
- 브라우저 회귀 검사: **96개 통과 / 실패 0개**. 새 AI 화면 검사 8개를 포함합니다. 설정 입력·키 유지와 삭제·배정 미리보기·작업 등록·직접 배정·평가·프로젝트 등록·사용량 표시를 확인합니다.
- 별도 테스트 서비스의 실제 화면에서 Git 프로젝트를 등록하고 담당 기준·동시 실행 수를 저장했습니다. 서비스 재시작 후 프로젝트와 설정이 유지되었습니다. 키가 없을 때 미리보기는 연결 안내를 표시하고 외부 API를 호출하지 않았습니다. 프롬프트 입력 너비와 화면 표시를 브라우저에서 확인했습니다.
- 구조도 생성기로 라이트·다크 SVG를 갱신했습니다. 브라우저의 별도 검증 페이지에서 `pauseAnimations()`와 `setCurrentTime()`을 사용해 두 테마의 2·8·14·24초 장면을 확인했습니다. AI 별도 경로 표기가 잘리거나 기존 장면을 가리지 않습니다.

기존 실행 중인 `pulse-ops-test_default` 네트워크와 `pulse-ops-test_test-ssh` 볼륨을 사용해 Alpine 3.23에서 `TestIntegrationRegisteredTargetsAndTerminal`, `TestIntegrationJumpPostgresRedis`를 실행했습니다. 등록 인프라·SSH 터미널, PostgreSQL·Redis의 직접 연결과 jump 연결 검사가 통과했습니다. 기존 테스트 스택을 다시 만들거나 재시작하지 않았습니다.

## 아직 확인하지 않은 범위

실제 Jev API 키와 Codex·Claude CLI 로그인 환경이 제공되지 않아 **실 계정으로 모델을 호출하는 전체 흐름은 실행하지 않았습니다**. 실제 API 이용 권한·요청 한도·모델 접근, CLI 설치 버전에 따른 동작과 도구 권한은 연결한 환경에서 추가 확인해야 합니다. 기본 Alpine 배포 이미지에는 실행 도구가 없으며 Linux/WSL 호스트 또는 별도로 구성한 실행 환경이 필요합니다.

담당 프로필의 초기 예시는 수정 가능한 운영자 선호이며, Codex와 Claude의 성능을 비교 측정한 결과가 아닙니다. 사용자 평가를 다음 판단의 문맥으로 전달하지만 학습 모델을 재훈련하지는 않습니다. Jev의 확신도와 에이전트의 응답 완료 상태는 작업 정확도나 테스트 통과의 보증이 아닙니다.

복합 프롬프트의 자동 작업 분해·의존 관계 조정·결과 병합, 기존 데스크톱 대화 재개, 자동 배포는 이번 구현에 포함하지 않습니다. 작업 공간은 검토를 위해 남으며 자동 삭제하지 않습니다. 프로젝트 등록은 최대 100개, 작업 보관은 1,000건이고 목록은 최근 200건을 표시합니다. Linux/WSL 실행 경로를 검증했으며 Windows 실행·운영체제 전체 보안 격리·운영 배포·MySQL/MariaDB/Oracle 실 연결은 이번 검증 범위에 없습니다.
