# 운영 검증 범위

## 이번 변경에서 확인하는 경계

- 인프라 등록이 유일한 목록 기준. 저장은 초안, 연결은 명시적 액션.
- 빈 접속 항목 허용, 수정 버전 충돌 검증, 점프 경로 순환/삭제 참조 차단.
- 서버 저장 AES-256-GCM, 응답의 비밀값 제외, 고정 SSH 호스트 키 검증.
- 운영 API 인증과 변경 요청의 동일 출처 검증. Go 단일 서비스의 Basic 인증, 단회 30초 터미널 티켓, WebSocket Origin 검증, 최대 8개 세션, 세션 2시간 제한.
- 비밀번호 및 PEM/OpenSSH 키, passphrase, 점프 서버, 실제 PTY 입력/출력/리사이즈/종료.
- PostgreSQL 읽기 전용 세션, MySQL·MariaDB·Oracle 통계 조회 전용 경로와 최소 조회 권한. 3초 쿼리 제한, 수집 동시성 4개, 15초 주기, 최대 35초 수집 시간. 실패 재시도는 지수 지연으로 최대 240초까지 늦춰 연결 폭주를 제한.
- 테스트/운영 Compose 및 Go 테스트 seed 컴파일 분리. 테스트 SSH 키는 전용 볼륨에서 생성.
- 지표 부재와 정상 0 구분. 인프라별 이벤트 평가 및 명시적 의존 그래프. 차트 조회 기간과 평가 표본 해상도 분리.

## 실제 검증 환경

Linux Docker의 API 3대, PostgreSQL, Redis, Nginx HTTP, SSH bastion과 SSH node를 사용합니다. Windows/macOS SSH 수집 분기는 구현했지만 실제 해당 OS 원격 서버 연결은 검증하지 않았습니다. 기본 SSH 설정에서 발견한 회사 서버에는 접속하지 않았습니다.

확장 테스트에서는 MySQL 8.4, MariaDB 11.4, Oracle Free 23.26.3 이미지의 직접 연결·SSH 경유 통계 수집, 잘못된 인증과 검증되지 않은 TLS 거부를 확인했습니다. Oracle Service name/SID 및 조회 권한이 없는 계정의 부분 수집 상태를 검증했습니다. [DB 지원 범위](database-engines.md)에 계정 권한, PDB 지표 차이와 미검증 기능을 기록합니다.

Go 단위/경합 검사와 격리 통합 테스트, 브라우저 네이티브 JavaScript 상태·상관관계 검증, 실제 브라우저의 등록/터미널/이벤트 그래프 검증을 수행합니다. 단위 테스트만으로 실제 고객망의 방화벽, 인증서, DB 권한을 보증하지 않습니다.

## 판매 운영을 위해 남은 항목

- 현재는 단일 워크스페이스와 단일 운영 계정. 조직 SSO/RBAC, 고객별 암호화 키/저장소/네트워크 격리, 사용자별 감사 식별을 추가해야 합니다.
- HTTPS 앞단, 최소권한 DB 계정, SSH 계정·허용 경로, 공식 OS별 검증과 키 교체/폐기 정책을 실제 환경에서 정해야 합니다.
- 등록/관측 SQLite는 단일 인스턴스용입니다. 다중 수집기, HA, 백업·복구, 중앙 불변 감사 저장소와 90일을 넘는 사건 보존은 추가 구현 대상입니다. 웹훅·Slack·Discord·Teams 수신처와 암호화 전송 대기열은 제공하지만 실제 조직 채널·권한은 해당 환경에서 검증해야 합니다.
- 200개 등록 상한은 검증된 운영 용량 보증이 아닙니다. 수집 동시성/관측량/디스크/DB 잠금과 다중 사용자 조회를 부하 측정해야 합니다.
- 연결 오류는 즉시 표시하고 재시도합니다. 서버도 수집 후 공유 규칙으로 발생·복구를 판정해 활성 수신처에 전달합니다. 수집 공백은 복구로 보지 않으며 재시작 후 상태·대기열을 유지합니다. 사용자별 처리 식별/당직 교대/에스컬레이션과 서비스 자체 중단에 대한 외부 감시는 추가 구현 범위입니다.
- 앱 내부/API별/JVM/Kubernetes/외부 세션 계측은 해당 서비스에 계측 계약이 있어야 합니다. 지원하지 않는 필드는 0으로 채우지 않습니다. 주/월 기준선, 장기 SLO와 복잡한 예측에는 충분한 장기 보존 수집 경로가 필요합니다.
- 취약점/라이선스 검토, 임계값과 히스토그램 버킷 조정, 리소스 제한, 장애 주입과 복구 시간 검증이 필요합니다.

이번 결과는 위 범위를 구분한 작동 가능한 제품 기반입니다. 다중 고객 SaaS의 운영 검증을 완료했다는 의미는 아닙니다.

이벤트 처리·메모, 전송 이력·재전송, 점검 시간·수신 분기·묶음·정기 요약과 인프라/대시보드 편의기능은 [별도 검증 기록](operations-convenience-verification.md)을 참고하세요.
