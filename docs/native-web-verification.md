# Go 단일 서비스 전환 검증

검증일: 2026-10-08. 기존 등록 저장소를 유지한 로컬 Docker Compose와 별도 운영 이미지에서 확인했습니다. 실제 고객 서버나 SSH 후보에는 접속하지 않았습니다.

## 변경 결과

- Go 실행 파일이 HTML/CSS/JavaScript, 지표 정의와 터미널 정적 파일을 포함합니다. Node, npm, React, Next, 프런트 빌드 및 별도 gateway를 제거했습니다.
- 화면의 Web Worker가 조회·규칙 평가를 수행하고 Canvas가 그래프를 그립니다. Go가 직접 수집·저장·API·인증·SSH 터미널을 담당합니다.
- 그래프 손잡이 드래그, 대상 강조, 합치기, 합치기 해제, 시계열 분리와 복구를 제공합니다. 원래 시계열·단위와 빈 구간을 보존합니다.
- 각 그래프 하단에서 포함된 시계열을 확인하고 표시/숨김 및 1~3600초 갱신을 설정합니다. 빈 값은 전체 설정을 따르며 브라우저에 저장됩니다.
- 운영 Compose는 Go 서비스 하나입니다. 테스트 대상과 선택적인 Prometheus/Grafana는 별도 테스트 구성에 남아 있습니다.
- README에 정적 구조도와 트래픽 흐름 GIF를 포함했습니다. 이미지 생성용 Python/Pillow는 제품 의존성이 아닙니다.

| DB 전용 실제 지표 검사 | PostgreSQL·MySQL·MariaDB·Oracle 정상 연결·응답 및 엔진별 통계 검증 통과 |
| 플랫폼 빌드 | Linux 운영 이미지, Windows amd64, macOS arm64의 CGO 없는 빌드 통과 |

최종 전체 지표 검사 시점에는 지표 정의 119개 중 **85개가 관측 가능**했습니다. 이 수는 표본 기간·대상 상태에 따라 바뀝니다. 미계측 지표, 한 시간/주간 이력이 부족한 지표는 정상 0으로 대체하지 않습니다. API의 백분위는 수집기 재시작 후 5분의 연속 표본이 쌓인 다음 검증했습니다.

회귀 검사는 인프라 간 값 혼용 금지, 실제 0/NULL/수집 공백 구분, 지속 조건·예측 최소 표본·SLO 창, 단위와 시계열 보존, 저장된 조합의 선택 범위, 독립 갱신 주기를 포함합니다. 전환 과정에서 발견한 Worker 초기 요청 유실과 최신 NULL 표본의 상태 판정도 회귀 검사로 고정했습니다.

## 실제 화면 검사

- 네 메뉴 전환, 인프라 선택·여러 대상 비교, 인프라 상세 그래프와 이벤트 관련 그래프 확인.
- 실제 마우스로 P99를 P97 위에 놓고 P95를 추가해 세 선을 합침. 원래 시계열·단위 유지, 합치기 해제와 새로고침 후 조합 유지 확인.
- 이벤트 관련 그래프의 시계열별 분리와 분리 취소 확인.
- 그래프의 개별 2초 설정 저장·재로딩 유지 확인. 빠른 그래프와 기본 그래프의 화면 갱신 시각이 독립적으로 진행하는 것을 확인하고 비교 그래프에 5초 설정 적용.
- 조건 검색·규칙 행 펼치기·대상별 근거와 그래프 확인.
- 주소와 비밀값이 빈 Oracle 초안 저장 후 테스트 초안 제거. 저장만으로 연결되지 않음을 확인.
- 테스트 SSH node의 실제 jump 터미널에서 읽기 전용 출력 명령 실행·응답 확인.
- 390px 화면에서 메뉴·이벤트 펼치기·가로 넘침 여부 확인. 데스크톱에서 브라우저 오류 로그 없음.

## 운영 이미지 검사

별도 임시 컨테이너를 UID 10001, 읽기 전용 루트, 임시 `/tmp`로 실행했습니다. 테스트용으로 생성한 운영 인증·암호화 설정을 사용했으며 종료 후 임시 컨테이너와 설정을 제거했습니다.

- 다른 작업 디렉터리에서도 내장 UI 제공.
- UI·정적 파일·API의 미인증 접근 401, 인증된 요청 성공.
- 상태 확인 경로, gzip 전송, ETag 조건부 요청 304 확인.
- 테스트 전용 경로 404와 빈 등록 저장소 확인. 자동 테스트 등록 없음.
- 운영 서비스 수 1개, 비특권 사용자 실행 확인.

HTTPS 인증서의 실제 운영 도메인 배포는 수행하지 않았습니다. 운영 origin/인증서/앞단 설정은 배포 환경에서 검증해야 합니다.

## 크기와 메모리 관측

| 항목 | 전환 전 | 전환 후 |
| --- | --- | --- |
| 제품 필수 컨테이너 | Next + Go + gateway, 3개 | Go 1개 |
| 제품 이미지 크기 | 합계 591,281,389 bytes | 59,912,265 bytes |
| 제품 컨테이너 메모리 관측 | 합계 108.125 MiB | 45.93 MiB |

이미지 크기는 로컬 이미지의 비압축 크기이며 공유 레이어를 차감한 다운로드량이 아닙니다. 약 89.9% 감소했습니다. 메모리는 각각 한 시점의 유휴 관측값이며 동일 부하 벤치마크, 처리량 또는 운영 용량 보증이 아닙니다. 테스트 DB·API·SSH 대상과 선택적 관측 도구의 자원은 이 제품 비교에서 제외했습니다.

화면의 1초/5초 갱신은 화면 조회 주기입니다. 실제 수집은 15초이고 API는 최대 3초 공유 캐시를 사용할 수 있습니다. 화면이 숨겨지면 조회를 중단하며, 보이지 않는 그래프는 필요할 때 생성·그립니다.

## 검증 범위의 한계

Windows/macOS 결과는 실행 파일의 교차 빌드 검증입니다. 실제 해당 OS 원격 서버의 SSH 수집은 아직 검증하지 않았습니다. 상용 Oracle의 다양한 버전·RAC 등도 별도 확인이 필요합니다.

현재 단일 워크스페이스·단일 운영 계정·단일 SQLite 구조입니다. 다중 고객 격리, SSO/RBAC, HA, 대규모 부하·복구 검증과 서버에서 지속 평가하는 장기 사건 이력·외부 알림은 [운영 과제](production-readiness.md)에 남아 있습니다. 이번 검증은 로컬 제품 기능과 배포 구성을 확인한 것이며 고객 운영 환경 배포나 판매 운영 승인으로 간주하지 않습니다.
