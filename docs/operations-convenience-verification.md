# 운영 편의기능 검증

검증일: 2026-10-09. 제안한 편의기능 12개를 기존 등록·수집·알림·대시보드 흐름에 연결했습니다.

## 자동 검사

- 기본/테스트 seed 빌드의 Go vet와 race 검사. 연동이 없어도 남는 이벤트 이력, 독립적인 처리 상태·메모, 버전 충돌, 암호화, 미관측 상태의 복구 방지와 반복 사건을 확인합니다.
- 환경·태그·규칙 분기, 점검 시작·종료, 점검 전에 대기하던 발생의 억제, 실제 HTTP 수신기로 전달되는 두 대상의 알림 묶음과 대상별 전송 결과를 검사합니다.
- 5회 실패 이력, 수동 재전송의 중복 예약 방지와 원래 이력 유지, 점검 중 재전송 억제, 저장된 보기·점검 설정 검증, 비밀값 없는 복제, CSV 입력과 일괄 작업의 최신 버전 검증을 확인합니다.
- 요약의 한국시간/월요일 예약, 동일 날짜 중복 방지, 재시작 후 발송 상태 유지, 실제 두 기간의 지표 평균 변화와 데이터 부재를 검사합니다.
- 실제 임시 HTTP 대상에 대한 DNS·포트·읽기 진단을 확인하며 초안이 활성화되지 않는지 검사합니다.
- 브라우저 회귀 검사 80개 통과, 실패 0개. CSV BOM·CRLF·따옴표, 수신 조건 편집, 점검 시간 입력, 전송 재시도, 처리·메모 저장, 이름 있는 보기, 태그 전체 검색과 진단 안내를 포함합니다.
- 기존 격리 테스트 스택의 등록·SSH PTY·단회 티켓 및 PostgreSQL/Redis 직접·SSH 경유 수집을 확인합니다. 기존 스택은 재빌드·재시작하지 않습니다.

## 실제 화면

별도 임시 미리보기에서 수신 조건·묶음·주간 요약 설정 저장, 로컬 수신기 테스트 전송과 전송 이력, 15분 점검 시간, CSV 인프라 등록·태그 표시, 선택 대상의 연결 시작과 실제 DNS/TCP/읽기 진단을 확인합니다. 저장된 대시보드와 전체 검색, 이벤트 처리 메모, 재시작 후 유지도 확인합니다.

README 구조도의 두 테마를 다시 생성해 각 장면을 브라우저에서 멈춰 배치를 확인합니다. 등록된 목표 유형·수집 간격·슬롯·계측 계약은 바꾸지 않았습니다.

## 한계

실제 Slack/Discord/Teams 자격증명·조직 채널 권한은 사용하지 않았습니다. 공급자 메시지 형식과 로컬 HTTP 전송을 확인한 결과이며 조직의 실제 수신 검증은 별도입니다.

일간/주간 예약은 테스트 시계를 사용해 경계와 재시작 동작을 검사했습니다. 실제 24시간/7일 대기 실험은 수행하지 않았습니다. 관측 데이터가 없는 이전 기간은 요약에서 비교하지 않습니다.

현재는 단일 운영 계정입니다. 메모의 사용자별 작성자, 당직 교대·에스컬레이션·SSO/RBAC와 외부 서비스 중단 감시는 추가 범위입니다. 이미 전송 중인 요청은 음소거·삭제 뒤에도 완료될 수 있고, 수신 후 응답 유실은 중복 수신을 만들 수 있습니다.

현재 테스트 스택에 없는 MySQL/MariaDB/Oracle 통합 검사는 이번에 실행하지 않았습니다. 데스크톱 내장 브라우저에서 실제 화면을 확인했으며 휴대전화의 실제 터치 환경은 검증하지 않았습니다. 운영 배포는 수행하지 않았습니다.
