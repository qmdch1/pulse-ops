# 이벤트 알림 연동 검증

검증일: 2026-10-09. 일반 웹훅, Slack, Discord, Microsoft Teams 설정 UI와 서버 전송을 추가했습니다. 실제 메신저 자격증명과 채널은 사용하지 않았습니다.

## 확인한 범위

- `golang:1.27`에서 기본 및 `testseed` 빌드의 `go vet ./...`, `go test -race ./...` 통과. 이름·주소·토큰 검증, API Origin 제한, 비밀값의 암호화·비공개 응답·수정 시 유지, 버전 충돌, 필터·비활성·수신처 교체를 검사했습니다.
- 발생 중복 억제, 지속 시간·NULL·수집 공백·인프라별 격리, 복구 시 최신 관측값, 저장소 재개 후 상태 유지, 전송 실패와 5회 재시도 한도, 대상 중지 시 대기열 정리를 검사했습니다. 임시 HTTP 대상의 연결 실패·복구를 실제 수집한 뒤 별도 임시 웹훅 수신기에 전송했습니다. 브라우저가 없는 상태에서 실행한 검사입니다.
- 메신저별 요청 형식, Discord의 전송 확인·자동 멘션 차단, 일반 웹훅 Bearer 헤더, HTTP 204/429, 리다이렉트 거부, 요청 시간 제한과 오류 메시지 비밀값 제거를 검사했습니다.
- 별도 격리 미리보기의 브라우저 회귀 검사 **72개 통과, 실패 0개**. 화면과 서버의 같은 사건 fixture, 공유 임계값, 비밀값 유지, 실패 시 재시도 UI, 새로고침과 저장이 겹치는 목록 갱신을 포함합니다. 실제 설정 화면에서 수신처를 저장하고 로컬 수신기에 테스트 전송, 저장 후 재시작 유지와 수정 화면의 비밀값 비공개를 확인했습니다.
- `alpine:3.23`에서 `go test -c`로 만든 통합 검사 실행. 기존 `pulse-ops-test_default` 네트워크와 `pulse-ops-test_test-ssh` 볼륨을 사용해 `PULSE_TEST_CONTROL`, `PULSE_TEST_SSH_JUMP` 검사 통과. 등록·실제 SSH PTY·단회 티켓, PostgreSQL·Redis 직접/SSH 경유 수집을 확인했습니다. 기존 테스트 스택은 재빌드·재시작하지 않았습니다.
- Python SSH 탐색 검사 2개 통과. 구조도 라이트·다크 SVG를 재생성하고 브라우저에서 `pauseAnimations()`/`setCurrentTime()`으로 각 2·8·18·24초 장면의 배치와 알림 경로를 확인했습니다.

## 검증의 한계

실제 Slack/Discord/Teams 채널의 자격증명·권한과 운영 네트워크는 검증하지 않았습니다. Teams는 Anyone 요청자 유형의 웹훅 수신 Workflow를 대상으로 합니다. 내장 브라우저의 화면 크기 변경이 적용되지 않아 이번 실제 UI 검사는 데스크톱 크기에서 수행했습니다.

장기 사건 검색, 다중 운영자/당직 교대·에스컬레이션, 서비스 자체 중단 알림은 범위에 포함하지 않습니다. 프로세스가 실행 중이어야 전송할 수 있으며, 수신 후 응답 유실은 중복 전달을 만들 수 있습니다. 이번 결과는 저장소 기능 반영이며 운영 배포가 아닙니다.
