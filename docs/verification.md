- Docker 테스트: 애플리케이션 서버 3대, PostgreSQL, Redis, Nginx 프런트와 Prometheus·Grafana·Alertmanager를 실행했습니다.
- 수집 대상 8개에 대해 정상 scrape를 확인했습니다. 98개 지표 계약은 모두 Prometheus 구문 오류 없이 조회됩니다. 실제 관측 수는 요청·오류 유무에 따라 변합니다.
- P50 ≤ P97 ≤ P99, 처리량 > 0, 실제 DB·캐시·인증 만료 계측을 확인했습니다.
- 불충분한 6시간 디스크 예측 및 1주 비교는 미관측으로 남습니다.
- API 입력 검증, 지속 시간·NULL·표본 공백, SLO 2창, 운영 인증 fail-closed, 사용자 정의 수집기 경보 등 단위 테스트 12개를 통과했습니다.
- SSH Include, wildcard 제외, 명령 비실행 테스트 2개를 통과했습니다. Windows 설정에서 연결 후보 5개를 발견했으며 접속하지 않았습니다.
- Prometheus 규칙 7개를 promtool로 검증했습니다.
- 테스트 Redis를 155초 중단했습니다. 실제 5xx 비율 10.14%, P99 약 4,704ms와 HighServerErrorRatio / HighTailLatency / CacheExporterUnavailable 경보를 관측했습니다. Redis를 복구하고 8개 수집 대상 및 테스트 서버 health가 정상임을 다시 확인했습니다.
- 브라우저에서 지표 검색·P97 상세·SSH 목록·경보 발생/해제 이력을 확인했습니다. 모바일 화면을 확인하고 모바일 구역 이동 시 메뉴가 닫히도록 처리했습니다.
- 조사 패널은 클릭 시점 스냅샷을 보존합니다. 브라우저가 새 데이터를 받아도 근거와 그래프가 서로 다른 시점으로 바뀌지 않습니다.
- 운영 Compose의 서비스 목록이 dashboard만 포함함을 확인했습니다. 실제 운영 서버에는 연결·배포하지 않았습니다.
