- Docker 데이터에서 API 3대의 동일 만료 규칙을 1종류·3건으로 표시했습니다. 클릭하면 발생 대상 3대와 등록된 PostgreSQL·Redis 의존 관계, 조건·지속 시간·대상별 근거, 43개 시계열의 7개 그래프가 표시되는 것을 확인했습니다. 다른 인프라의 값을 섞어 이벤트를 새로 평가하지 않습니다.
- 인프라 상세 모달의 이벤트 클릭으로 대시보드의 관련 그래프가 열리고, ‘관련 인프라의 전체 그래프’가 하단의 5개 인프라를 선택해 이동하는 것을 확인했습니다.
